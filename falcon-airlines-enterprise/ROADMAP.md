# Roadmap

- Monorepo structure
- Spring Boot project with Maven
- PostgreSQL and Flyway configuration

- Notifications
- Delay prediction
- Analytics dashboard
- React frontend

## Phase 5 — Enterprise Hardening

- Multi-region deployment
- SLOs and observability
- PCI and GDPR compliance artifacts
- Performance testing
